# DotaMind

Приложение для iPhone и iPad со статистикой Dota 2. Главное в нём — **Turbo-статистика**, которой нет ни в самой Доте, ни на большинстве сайтов. Данные берутся из [OpenDota API](https://docs.opendota.com).

- **Голографическая карточка игрока** в стиле редкой коллекционной карты: Metal-шейдер, наклон по гироскопу, переворот по тапу.
- **Режимы Turbo / Обычные / Все** на всех экранах: герои, средние, форма по неделям, рекорды, достижения.
- **Турбо-рейтинг** — оценка MMR для Turbo по системе Elo, если бы Valve его считала.
- **Матчи прямо в приложении:** составы, предметы, график золота.
- **Советы** по твоей статистике, страница героя с предметами и сравнением со всеми игроками.
- **Драфт-помощник:** кого взять против врагов по твоим матчам.
- **Напарники**, винрейт соло и в пати, сравнение с другом.
- **Виджет** на экран «Домой», уведомления после матча, экспорт карточки в PNG.
- **Дизайн iOS 26 Liquid Glass**, раскладка для iPhone, iPad и складных экранов.

## Запуск

Нужны Xcode 26 и iOS/iPadOS 26. Откройте `DotaMind.xcodeproj`, схема `DotaMind`.

Без сети (или со сломанным DNS в симуляторе) приложение показывает встроенный снимок данных. Аргументы запуска для отладки (Product → Scheme → Edit Scheme → Arguments):

```
-DMSteamID 76561199211436527   # войти сразу
-DMOffline YES                 # только снимок, без сети
-DMTab profile|matches|draft|settings
```

Обновить снимок: `python3 Scripts/make_demo_data.py [account_id]`.
